# TinyML Practice

A dedicated repository for learning and implementing Tiny Machine Learning (TinyML) on resource-constrained devices. This project explores the intersection of machine learning and embedded systems, focusing on deploying efficient models to microcontrollers.

## 📂 Project Structure

- **[basics/](file:///b:/tinyml-practice/basics)**: Fundamental concepts and simple ML models.
- **[tensorflow-lite/](file:///b:/tinyml-practice/tensorflow-lite)**: TensorFlow Lite Micro implementations and model conversions.
- **[edge-ai-projects/](file:///b:/tinyml-practice/edge-ai-projects)**: End-to-end Edge AI applications and prototypes.
- **[datasets/](file:///b:/tinyml-practice/datasets)**: Curated data for training and testing small-scale models.
- **[notebooks/](file:///b:/tinyml-practice/notebooks)**: Jupyter notebooks for model training, quantization, and evaluation.
- **[microcontroller-deployment/](file:///b:/tinyml-practice/microcontroller-deployment)**: Source code for deploying models to various MCU platforms (AVR, ESP32, STM32, etc.).
- **[docs/](file:///b:/tinyml-practice/docs)**: Documentation, research notes, and learning resources.

## 🚀 Getting Started

This repository is designed to track progress through the TinyML ecosystem, from data collection and model training to final deployment on hardware.
